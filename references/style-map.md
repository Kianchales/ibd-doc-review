# IPO 文档样式映射速查表（style-map.md）

> 数据来源：模板 docx 的 styles.xml **实证提取**（2026-08-25 解析）：
> - 招股书版 = `报告模板.docx`（适用：招股书章节 / 报告 / 备忘录 / 尽调报告等正式文档）
> - 反馈回复版 = `反馈回复样式.docx`（适用：审核问询回复/反馈回复/落实函回复）
> - 表格样式（a4/a5/a6）两版一致
>
> 模板路径（skill 自带）：`assets/templates/`（相对本 skill 目录；**使用者替换模板即定制输出样式**）

## 页面设置（两版一致）

- A4（21.00cm × 29.70cm），页边距上下左右均 2.54cm
- docDefaults：西文 Times New Roman / 中文宋体，默认字号 12pt（小四，sz=24）
- 正文行距统一 1.5 倍（spacing line=360 lineRule=auto）

## 三、反馈回复排版范式（document.xml 实证）

反馈回复模板内置示例结构（照此组织）：

```
问题1.XXXX                    → 0011（黑体 16pt 两端对齐，问题编号标题）
问题正文内容，内含多个明细问题   → 001（黑体缩进，监管问题原文，逐题展示）
【回复】                      → 000（回复正文）
一、明细问题1                  → 002（加粗）
二、明细问题2                  → 002（加粗）
问题2.XXXX                    → 0011
...
```

**合规展示铁律**：监管问题原文必须 001 黑体、回复正文必须 000 宋体——黑体宋体对照本身就是审核合规展示，不得混用（实证：反馈回复模板 document.xml 第 1/6 段为 0011，第 2/7 段为 001，第 3/8 段为 000，第 4-5/9-10 段为 002）。

## 四、表格样式（两版一致 · a6/a5/a4）

| 样式ID | 名称 | 用途 | 格式 |
|--------|------|------|------|
| **a6** | 报告表格 | 表格单元格 | 默认 9pt（小五，sz=18） |
| **a5** | 表格前单位 | 表格上方单位行 | 右对齐，默认字号（szCs=24） |
| **a4** | 表格后说明 | 表格下方说明行 | 两端对齐，默认字号（szCs=24） |

> 表格级/行级/表头结构/对齐规则等**结构性规范见 `rules.md` 第二节**（三线表规范 v2：100% 页宽自动调整、纯黑边框、支持两级表头+跨列/跨行合并、数字右对齐、合计行加粗跨列——表格模板.docx 示例表格完整实证 + 2026-08-25 用户裁定）。
